# Игра «Крокодил» 🐊 — Руководство пользователя

Для успешной компиляции, сборки и запуска проекта на вашем компьютере должны быть установлены следующие инструменты:

1. **Операционная система:** Windows 11.
2. **Среда разработки (IDE):** [Qt Creator](https://www.qt.io/download).
3. **Компилятор:** MinGW 64-bit.
4. **Система контроля версий:** Git (для клонирования репозитория).

### Шаг 1. Клонирование репозитория
1. Откройте терминал и выполните команду для клонирования репозитория со всеми исходными файлами к себе на компьютер:
git clone (https://github.com/plum591/crocodile.git).

### Шаг 2. Открытие проекта в Qt Creator
1. Запустите Qt Creator.
2. Нажмите Файл -> Открыть файл или проект.
3. Перейдите в склонированную папку qt_crocodile/crocodile и выберите главный файл конфигурации проекта: crocodile.pro.
4. В появившемся окне настройки проекта выберите ваш комплект сборки (например, Desktop Qt 6.x.x MinGW 64-bit) и нажмите кнопку Configure Project.

### Шаг 3. Сборка и запуск игры
1. В левом верхнем углу во вкладке сборка выберите "Запустить qmake".
2. Нажмите кнопку «Запустить» (зелёный треугольник в левой панели).

4. Среда запустит стартовое окно приложения.

### Шаг 4. Как играть 
1. Когда откроется начальный экран нажать кнопку "Начать игру".
2. Правила игры есть на каждой странице в правом верхем углу (кнопка "?").
3. Также в левом верхнем углу есть кнопка меню, она позволяет сбросить игру или закрыть приложение.
4. После запуска игры откроется окно добавления участников и выбора режима игры.
5. Добавьте минимум 2 игроков и выберите подходящую для вас сложность игры.
6. Нажмите кнопку старт.
7. Первый добавленный игрок выбирает слово.
8. Нажмите кнопку продолжить.
9. Игрок 1 рисует выбранное слово.
10. Тот игрок который угадал слово которое рисует игрок 1 получает 3 балла, также как и игрок 1.
11. Игра завершается когда один из игроков наберет 20 баллов.
